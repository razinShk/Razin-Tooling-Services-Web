# Razin Tooling Services - SEO & Deployment Strategy 🚀

This document encapsulates the deployment pipeline and the 12-month SEO architecture required to dominate Indian industrial search rankings for Tooling Services, Die Proving, and Skilled Manpower.

## 1. Vercel Deployment Instructions

The repository is fully configured for zero-configuration deployment on Vercel.

1. Push your code to a GitHub, GitLab, or Bitbucket repository.
2. Log in to [Vercel](https://vercel.com/) and click **Add New** > **Project**.
3. Import the `RazinToolingServices` repository.
4. **Framework Preset:** Vercel will automatically detect `Next.js`.
5. **Environment Variables:**
   - Set `NEXT_PUBLIC_SITE_URL` to your production domain (e.g., `https://razintoolingservices.in`).
6. Click **Deploy**. Vercel will build the Static Site Generation (SSG) routes natively.
7. Under Project Settings -> Domains, add your custom domain. Vercel automatically secures it with an SSL certificate.

## 2. Google Search Console Setup Steps

1. Wait for Vercel to attach the custom domain.
2. Go to [Google Search Console](https://search.google.com/search-console).
3. Click **Add Property** and select the **Domain** (DNS verification) or **URL prefix** method.
4. If using Vercel DNS or Namecheap, add the provided `TXT` record to your DNS settings.
5. Once verified:
   - Navigate to **Sitemaps** on the left menu.
   - Submit: `https://razintoolingservices.in/sitemap.xml` (This is auto-generated by the `sitemap.ts` file in the codebase).
6. Google will immediately begin crawling your 18 dynamic location pages, 9 service pages, and 10 blog posts.

## 4. Backlink Acquisition Strategy

Industrial SEO relies heavily on authoritative, niche-relevant backlinks rather than high-volume spam links.

1. **OEM Vendor Portals:** Request backlinks from the public-facing supplier/vendor portals of past clients (Tata Motors, GE Stamp).
2. **Directory Listings:** Submit the company profile to high-authority manufacturing directories:
   - IndiaMart (with link back)
   - TradeIndia
   - Engineering-focused global directories (e.g., ThomasNet equivalent in India)
3. **Local Chambers of Commerce:** Acquire a backlink from the Mahratta Chamber of Commerce, Industries and Agriculture (MCCIA) Pune directory.
4. **Guest Technical Writing:** Offer Asif N Shaikh's expertise to write technical columns on Indian manufacturing portals (e.g., *Auto Components India*, *Manufacturing Today India*) featuring a backlink to the domain.
5. **Press Releases:** Distribute a quarterly PR acknowledging major OEM die-proving successes or the integration of new 210mm deep draw techniques.
